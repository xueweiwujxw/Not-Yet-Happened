# 第二章可玩切片：门后有人

状态：已实现文字剧情、一次性往事窗口、第一章衔接与独立章节存档。
现有第二章 3D 值班室入口，真实录音与照片图像尚未制作；约二十分钟仍是设计目标，不是实测时长。

## 进入与共同事实

第一章完成后选择「前往第二章」。继承经过合法操作回放验证的第一章记录，
包括可选合影、通知、信件字句，不通过任意事实字典导入剧情。
林澈和栞已生还；姐姐失踪，生死尚未确认。所有路线保留这些事实。
原有单房间沙盒仍独立，不把它的安全随机数带入正式剧情。

## 现在与往事

现在调查旧电话与停电记录，听原有录音，两项顺序可交换。录音已确认的前缀固定不变。
只有完成调查并明确选择「确认范围，进入往事空白」，才来到十四年前 18:10。
界面始终标明时间、范围和后果；没有真实倒计时，不催玩家在读字时决定。

| 动作 | 固定什么 | 不固定什么 |
| --- | --- | --- |
| 先打电话 | 当年拨号；读完后确认电话字句与灯柜位置知识 | 当年接好照明、放下检修梯 |
| 先监听 | 推进至 18:20，未拨号则固定未拨号；读完后确认脚步 | 脚步身份、姐姐生死 |
| 开门确认 | 关闭拨号机会；读完后确认接应情况并关闭窗口 | 姐姐离开孩子后的路径与命运 |
| 返回现在 / 重听 | 保留既定动作，可回顾既定转录 | 不能重开窗口或改选 |

打电话后开门，周启明在门口接应，林遥赶到；未打电话则栞先独自等候，林遥稍后带孩子去船边。
开门动作包含等到姐姐到达的片段，界面与对白标明 18:20—18:24。
两个孩子 18:27 离开、18:40 到达避难所是共同历史，不作为本章奖励或惩罚。
没打电话则没有灯柜的提前提示，但第三章仍能取得操作图，不能锁死主线。

两个明确编写的局部候选由电话动作约束筛选，不调用随机解析器。
唯一候选不等于已看见：接应身份仍要到开门对白读完才写成确认事实。
动作一经选择即固定；未读完的证据保持 pending，恢复存档后接着读。
不合法的观察冲突拒绝整个提交，保留最后一句与操作日志，不吞掉对白。

## 叙事与后续边界

章末栞问「你记得我那时很害怕吗」。林澈停止重放录音，两人离开值班室。
第一章已听清的姐弟日常录音、第二章已听清的雨声与提问都不改写。
新确认的回答另列调查转录，不声称凭空改变旧录音的音轨。

第四章只可能操作仍未确认的备用照明接线与检修梯；本章没有这两个动作或它们的否定事实。
「知道灯柜在哪」不等于「当年灯已接好」。姐姐命运和第三章人际选择由后续篇章处理。

## 3D 值班室

第二章顶部的「3D」按钮进入固定镜头值班室，与文字界面共用同一个会话。
沿用 WASD/方向键/左摇杆移动、E/A 主操作、Tab/B 返回本章笔记；其他操作仍可点按钮。
电话在左侧桌面、录音机在右侧桌面，监听和开门在后门附近，离开在左前方出口。
进入往事仍需在录音机处明确选择并阅读范围说明；没有实时倒计时。

往事中的主角模型缩小，停电时灯灭、环境变冷。监听不显示门后人物；读完开门对白、
确认窗口事实后才打开模型门并显示栞，有电话接应时额外显示管理员。姐姐到来仍由
文字叙述，不声称已制作整个接送过场。回到现在关闭门口往事画面，不撤销任何事实。
灯柜和时钟是不可交互的场景道具，不新增照明/放梯操作；钟面不承担准确报时，
HUD 文字阶段才是时间来源。第二章关闭厨房占位音效，避免合成声音暗示门后证据。

角色位置不写入存档。跨章返回会释放 3D 场景和摄像机。章节三至六仍为文字界面。
自动测试覆盖两条空间操作路线、远距离拒绝、pending 证据不可见、时间阶段、事实隔离、
重访不可重开、隐藏视图输入与跨章退出。Actions 新增 `keeper-previews`，包含现在、
停电和观察后三张实际 Godot 截图。仍需物理显卡和真人操作验收。

## 导航与存档

返回第一章是查看本次记录，已完成章节不能改变事实；再进入第二章保留进度。
重新开始或读取另一份第一章存档，明确替换本次尝试，并丢弃依赖它的内存中第二章。
另开第二章尝试保留第一章记录；这是显式新尝试，不是本轮撤销事实。都不自动修改磁盘存档。

第二章手动槽 `user://chapter-two.json` 包含完整第一章回放与第二章事件。
初始界面可直接读取第二章，无需重通第一章，会同时恢复对应的第一章记录。
前两章各一个槽；第三至六章共用一个连续篇章槽，均保留上一份有效备份。协议见 [存档格式](save-format.md)。
