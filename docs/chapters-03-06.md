# 第三至六章：完整文字主线

状态：已实装，能从第一章连续玩到四种结局，并在对白中途或结局后保存恢复。
这是延续前两章规格的文字交互版，不是已制作好 3D 场景、角色配音或实测两三小时的成品。
中文对白分别位于 `src/content/chapter_three.gd` 至 `chapter_six.gd`。

## 第三章：没有寄出的信

照相馆中，栞给林澈留了不加糖的豆浆。沈琴交出姐姐的学校录取信：她不只想救弟弟，也想去外地上学。
林澈责怪栞早就知道，她回答「你那时只有十岁。现在不是了」。这是人物冲突，不是解锁道具的密码。

调查顺序允许变化：确认设备铭牌，阅读签名报告，核对巡查图，询问周启明，取得操作图。
报告只固定字句；巡查图的覆盖范围与周启明说过什么分别记录，不生成“防波堤无人”的事实。
查看担架照片是独立可选动作，图中身份不可辨，不确认姐姐死亡。

第二章拨过电话者已知灯柜位置；没拨者可照图核对旧柜标记，补足同一信息。两者都能完成救援准备。
接受或不接受道歉可选，均不影响工具。播放栞不愿听的录音不提供救援信息，只记录关系后果。
主线离开要求录取信、操作图、柜子位置信息和对栞拒绝的明确回应。

## 第四章：七分钟

两段窗口都以明确按钮进入，不存在真实倒计时。读字不会偷偷消耗机会。

1. 18:12—18:19：按已取得的图接妥独立电池备用照明，不修主电路，也不重选第二章的电话。
2. 18:26—18:27：结束接线窗口后，使用矮处手柄放下检修梯。不能回前一窗口补灯。
3. 明确确认平台，或结束重访保留未确认。确认会转到已上船的观察位置，并固定未做的准备为未完成。

| 备用灯 | 检修梯 | 选择确认平台时看到什么 |
| --- | --- | --- |
| 已接 | 已放 | 姐姐经检修路安全撤离 |
| 已接 | 未放 | 姐姐在通路中断处失足 |
| 未接 | 已放 | 姐姐在黑暗平台失足 |
| 未接 | 未放 | 姐姐失足 |

闪电短暂照清失足，但风雨遮挡后续。第四章只确认经过，不写入死亡。
不确认则保留平台未知，即使某些准备已做也不自动补完；提前结束空白不伪造尚未完成动作的否定事实。
所有已确认动作保留。本轮窗口关闭，不能重复刷结果；显式另开尝试或读档是另一轮记录。

姐姐与十岁的林澈隔门说话：「我先送你们上船」「我不是说现在」。回到现在，学校录取信提醒他：
让她有生路，不意味着能要求她的人生围着自己转。

## 第五章：有人在等她

- 安全经过：内港撤离记录指向外地维修站。核对证件、清晰照片与身份资料才确认生还。
- 失足经过：跨镇档案记录数日后的身份未明遇难者，与次日未找到遗体不冲突。清晰身份与死亡记录相符才确认死亡。
- 平台未知：不凭空指定一份唯一身份档案，整理来源并封存未知。

查看记录来源不等于核实身份。各路线都可明确封存；核实或封存后，本轮不再重开身份选择。
封存没有销毁原始资料，也不保证姐姐活着。安全路线不会提供死亡档案，失足路线不会提供活着的姐姐。

生还后可选择联系或暂不联系。联系才有姐姐的回答：住院、恢复、离开的愿望、多年不敢解释的沉默。
她承认伤害，不用失忆免责。重逢发生在入秋，不是当夜让她瞬移回厨房。

共同收尾包括便利店饭桌与报告更正。许岚直接叫栞的名字，栞不再为生还道歉。
公开更正与旧报告同时保存。死亡路线里另存的姐弟日常片段不是强制重播栞拒绝听的尖叫。

## 第六章：下一班车

纪念文字只依据已经核实的状态：撤离生还、台风事故遇难，或失踪且去向未确认。
栞是否参加合照取决于第三章边界选择；玩家可选择自己入镜或只拍风景，不会改写第一章的照片。
然后只有“赶下一班车”，没有直接选结局的菜单。

| 先前条件 | 结局 | 情感收尾 |
| --- | --- | --- |
| 生还且已寄信 | 厨房的灯 | 入秋短暂团聚，「那我买三天的菜」 |
| 生还且暂不联系 | 她的远方 | 保留地址，不假装已彼此原谅 |
| 死亡已核实 | 把名字留下 | 不只记录牺牲，也记下学校、维修和日常 |
| 身份未核实并封存 | 夏日留白 | 保管证据，承认未知，继续自己的生活 |

关系只影响合照，不能交换生死；全流程没有随机生死判定。

## 实现边界

`finale_rules.gd` 负责显式动作前置、结果与结局判定。各章内容文件保存对白和事实来源。
`finale_session.gd` 负责原子观察、章节进度与合法事件回放；四个准备候选历史由既定动作约束。
`finale_screen.gd` 只显示会话结果，`finale_navigation.gd` 负责前后章节切换，无业务规则混入 UI。

第三至六章共用连续存档槽，包含前两章记录。直接加载与返回旧记录均使用匹配的历史。
重开前章会清除依赖它的后续内存状态，不删除磁盘文件。见 [存档协议](save-format.md)。
